**Switchboard is now InputFlip**, with a new look and eight new features. Download `InputFlip-Setup.exe` below and run
it. Already have Switchboard 1.0? Click **Update** in its title bar; your settings stay.

### New

- **Scenes:** switch several monitors at once and set their brightness; press again to go back.
- **Command line and `inputflip://` links** for scripts, desktop shortcuts, AutoHotkey and Stream Deck
  (`InputFlip.exe --switch MSI PS5`, `inputflip://scene/Console`).
- **USB rules:** when a USB device (a keyboard on a USB switch box) leaves or comes back, switch the monitor. A software KVM.
- **Pop-up picker** next to the mouse (`Ctrl+Alt+Shift+P`) and a short note after a switch, on a screen you can still see.
- **Brightness, contrast and speaker volume** per monitor.
- **Tray icon** with every scene and input, and an option to keep running when the window closes.
- **Lock and sleep rules:** switch when the PC locks, unlocks, sleeps or wakes.
- **New look:** inputs as big tiles, the one showing now in blue; light and dark; a new icon.

### Changed

- The app, exe and window are called InputFlip. The install folder stays `%LOCALAPPDATA%\SwitchboardApp` so updates
  keep working; settings stay where they were.
- Updates now come from GitHub releases.
- A cleared shortcut no longer comes back after a restart.

The installer isn't code-signed yet: if SmartScreen warns, click **More info**, then **Run anyway**.
